Assemble the dataset

Evaluate before you buy

Model teams don’t buy data blind. Pull a representative sample under an evaluation license, and read the auto-generated datasheet first.

Deliver into your pipeline

API-first: decide in the app, take delivery over the API — bulk snapshots, delta feeds, and webhooks when new content matches.

Bulk snapshot

Full dataset + metadata to S3 / GCS / Azure, in your format — raw assets, structured metadata, or precomputed embeddings (skip your ETL).

→ S3 · GCS · Azure

Delta feed

Monthly increments of new matching content, so continuous retraining always has fresh data.

→ Recurring

Webhooks

Fire when new content matches a saved search or when an eval subset is ready.

→ Event-driven

Create a delivery — the whole purchase is an API call

# Export dataset dst_8f3k2 to your bucket — assets + metadata + embeddings
curl -X POST https://api.dataplatform.example/v1/datasets/dst_8f3k2/exports \
  -H "Authorization: Bearer $DATA_PLATFORM_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "destination": "s3://acme-ml/fine-tune-q3",
    "format": "assets+metadata",
    "embeddings": true,
    "delta_feed": "monthly"
  }'

# Get notified when new content matches your saved search
curl -X POST https://api.dataplatform.example/v1/webhooks \
  -d '{"event": "saved_search.new_matches", "target": "https://acme-ml.example/hooks/shutterstock"}'

Supply flow — new opt-in matches per month

Delta feeds make the relationship recurring instead of one-off: what the contributor network uploads every day becomes your retraining loop.
